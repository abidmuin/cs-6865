Exercise 2 Modelling stop and wait protocol using TCP

 

2.1.      Modify the tcl code (tested in 1.1 above) following the instructions below. Test the modified code.

 

a.      Change the sending agent form UDP to TCP, specify the packet size 500 and the (maximum) window size 1, and attach it to the sending node:

set tcp0 [new Agent/TCP]

$tcp0 set packetSize_ 500

$tcp0 set window_ 1

$ns attach-agent $n0 $tcp0

b.     Change the traffic application agent from CBR to FTP and attach it to the sending agent (again modify the code from 2.1)

 

set ftp0 [new Application/FTP]

$ftp0 attach-agent $tcp0

 

c.      Change the traffic sink from the Null agent to the TCPSink agent

 

set sink0 [new Agent/TCPSink]

$ns attach-agent $n1 $sink0

 

d.     Finally modify the $ns start and stop commands to reflect the new design of the simulation experiment (you may need to find a web reference on how to start FTP flows in ns2).

e.     Run the simulation, observe the traffic in nam in slow motion and then comment on the differences between the original Mark Greis’ experiment (i.e. Exercise 1.1 in this lab) and your new simulation. What is the main difference (from the original experiment from Exercise 1.1) in the traffic pattern visible in nam? Show the new source code and one simulation screen capture (call it “stop and wait TCP flow example”) in your lab report.
