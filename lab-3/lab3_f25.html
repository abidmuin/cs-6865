Exercise 2 (two competing CBR flows)

Create a new simulation with two CBR sources at nodes n0 and n1 sending data over UDP to nodes n4 and n5. The flows n0-n4 and n1-n5 share the bottleneck link n2-n3. Set the sending rate of each CBR source to 800Kbps (equivalent to 80% of 1Mbps link utilization). What value needs to me used for the interval_ CBR flow parameter? Consequently, when both CBR sources are sending data at the same time, the cumulative load on n2-n3 will be 1.6Mbps (which is more than the n2-n3 link capacity). Run the simulation for 25 seconds, with the first flow n0-n4 sending data from 1 second to 20 seconds, and the second flow n1-n5 sending data from 5 seconds to 15 seconds (you may adjust these intervals if needed). Use different colors for marking each flow in nam.

a)     Run the simulation and capture two screenshots in nam: when only one follow is sending and the other when both flows are sending and packets are being dropped.

b)    Modify the simulation code  (add the record() routine etc., follow the example from Exercise 1) to plot the throughput for each flow in Xgraph. Show the modified source code. Run the simulation and comment on the generated throughput graphs. (Show the graphs. What’s the throughput when only one flow is sending? What’s the throughput for each flow when both flows are sending? What’s the cumulative throughput when both flows are sending?)

c)     Inspect the nam trace file and count all dropped packets (indicate the total number of dropped packets, and then the number of packets dropped for each flow). Comment on the results.

 

Exercise 3 (CBR flow competing with FTP over TCP flow)
